# Contributing to feature-lists

These rules are mandatory for every contributor, human or automated. Pull requests that break them are not merged. They follow the rules of the [flagscope](https://github.com/flagscope/flagscope/blob/main/CONTRIBUTING.md) repository, plus the rules for lists below.

## Lists

- A list comes from a real scan of an installed Windows build with flagscope. Lists edited by hand, merged from other sources, or generated by other tools are not accepted.
- One build per pull request, one file per build, at the path `<architecture>/<major>/<major>.<revision>.txt` (see `README.md`).
- The file is committed exactly as flagscope wrote it: header lines, sorting, and line format unchanged.
- A list that already exists is replaced only to fix an error, with the reason in the pull request description.
- The pull request description states how the build was identified (`winver` output) and the flagscope version used.

## License and sign-off

- The data is dedicated to the public domain under CC0-1.0 (see `LICENSE`). By contributing, you agree that your contribution is released under the same terms.
- Every commit carries a Developer Certificate of Origin sign-off (`git commit -s`), which adds a `Signed-off-by:` line with your real name and an email you control. A GitHub no-reply address is accepted. Commits without it are rejected.

## Authorship and AI tools

- Every commit, push, pull request, review, and release is the responsibility of a human author, under that person's own name.
- AI tools may assist, but they are never the author, the committer, or the account that opens a pull request. Commits do not carry AI identities in `Author`, `Committer`, `Signed-off-by`, or `Co-authored-by`.
- Every rule in this document applies to AI-assisted work exactly as it applies to work done by hand. AI agents working in this repository read `AGENTS.md` and this document before acting, and stop to ask a human when an action would break a rule.

## Review and merging

- Every pull request needs at least one approving review from a maintainer before it is merged.
- Automated checks and AI review may run on pull requests, but they are advisory only and never replace human approval.
- Changes reach the default branch only through pull requests.

## Language and terminology

- Everything in the repository is written in English.
- Terms follow ISO/IEC/IEEE 24765:2017 and the glossary of the flagscope repository (`docs/00-context.md`).

## Repository content

- Only lists and the files that describe this repository are committed.
- Never committed: credentials, tokens, personal data, machine-specific paths or user names, symbol files (`*.pdb`), Windows binaries, logs, and editor or operating-system files.
- A secret that reaches a commit is treated as leaked: revoke and rotate it first, then remove it from the history.
