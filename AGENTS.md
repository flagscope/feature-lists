# feature-lists

## Repository rules

The rules for this repository live in [`CONTRIBUTING.md`](CONTRIBUTING.md). They are mandatory for agents as well as people. Read them before any change, commit, or pull request. In particular:

- Commits, pushes, and pull requests are authored by the responsible human, never under an AI identity, and every commit has a DCO sign-off.
- Everything is written in English, with precise technical terminology.
- Lists are committed exactly as flagscope wrote them. Never create, edit, or merge list contents by hand.
- No sensitive data, symbol files, binaries, or local files are ever committed.

## Where decisions live

This repository holds lists, the files that describe it, and the format check in `.github/`. The decisions that govern it are recorded in the flagscope repository (https://github.com/flagscope/flagscope): layout, file format, and license in `docs/features/published-lists/decisions.md` (AD-16); the format check in `docs/features/list-format-check/` (stories HU-18 and HU-19, decisions AD-25 and AD-26).
